在线学习视频平台 — Full-Stack Build

一个覆盖用户中心、视频内容展示、互动功能、搜索发现与后台管理的全栈在线学习视频平台， 涵盖注册登录、视频分片上传、评论弹幕、点赞投币、关注粉丝、播放统计、搜索热词、 视频推荐、内容审核与统计分析等核心业务场景。

技术栈
  • Spring Boot
  • MyBatis
  • Redis
  • Elasticsearch
  • Vue
  • MySQL

A. 我负责的内容

  • 用户注册登录、Token 生成与校验、关注/粉丝、个人资料编辑
  • 视频详情查询、视频列表分页、推荐视频、分类筛选、热门视频接口
  • ES 索引创建、视频文档同步、搜索高亮、排序及分页实现
  • 视频上传状态管理、分片信息记录、上传完成后的入库与队列写入
  • 播放量、评论量、粉丝量、点赞量的日统计汇总

B. 项目难点突破

  • 01
    大文件分片上传一致性

    通过 Redis 保存上传状态与分片索引，解决多次断点续传导致的重复上传与状态丢失，提升上传成功率与用户体验。

  • 02
    用户登录态安全

    通过 Redis 存储 Token 与过期时间，配合校验机制实现登录态续期与失效管理，保障登录状态一致性与安全性。

  • 03
    视频搜索性能瓶颈

    使用 Elasticsearch 构建视频全文索引，通过 IK 分词和字段映射优化搜索效果，提升命中率与响应速度，支持海量内容检索。

  • 04
    关注/粉丝数据一致性

    在关注、取消关注、粉丝计数等关键操作中统一使用事务与业务校验，避免数据不一致导致粉丝数错误与页面状态异常。
